# Skillentrix_Intern
Arduino-based DC Motor Speed and Direction Control using L293D, 16×2 LCD, and Potentiometer with Tinkercad simulation.
Features
PWM-based DC motor speed control (0–100%)
Forward and Reverse motor direction control
Real-time LCD display
Push-button direction switching
Tinkercad simulation compatible
Beginner-friendly embedded systems project


Components Used

Arduino Uno
L293D Motor Driver IC
DC Motor
16×2 LCD Display
10k Potentiometer (Speed Control)
10k Potentiometer (LCD Contrast)
Push Button
220Ω Resistor
Breadboard & Jumper Wires


Technologies

Arduino IDE
Embedded C/C++
PWM Motor Control
Tinkercad Simulation

Applications

Conveyor Belt Systems
Industrial Automation
Motor Control Systems
Embedded Systems Learning
Robotics
